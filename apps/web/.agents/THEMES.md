## Brand & Style

The design system embodies an esoteric, high-stakes intersection of autonomous artificial intelligence and decentralized execution: **Chiaroscuro Cybernetics**. It draws heavily from luxury horology, classified intelligence terminals, and cinematic sci-fi interfaces.

The emotional arc is deliberate:

- **Absolute Secrecy & Sacred Trust:** Operating within an obsidian void, the UI avoids hyper-active neon noise in favor of deep atmospheric shadows punctured by precise, warm incandescent beams.
- **Architectural Precision:** Every cryptographic signature, agent negotiation, and consensus state feels weighted, immutable, and precious.
- **Cinematic Elegance:** The visual signature pairs massive negative space with whisper-thin luminescent structures, projecting elite engineering and quiet authority over multi-agent consensus networks.

## Colors

The palette operates on extreme dynamic contrast: an ultra-abyssal canvas illuminated by warm lantern light and deep ambient purple undertones.

### Foundational Canvas

- **Void Obsidian (`#050308`):** The ground floor; absolute deep black with an ultra-faint violet cast.
- **Surface Elevation 1 (`#0B0714`):** Primary panel container fill.
- **Surface Elevation 2 (`#120924`):** Active or elevated cards, terminal nodes, and drawer overlays.
- **Surface Border Accent (`#2E1A47`):** Structural edge definition.

### Illumination & Highlights

- **Incandescent Core (`#FFF7EB`):** Maximum intensity; used exclusively for active typographic highlights, focal points, and crisp lantern beacons.
- **Warm Filament (`#FCE7C8`):** Primary brand accent; golden parchment white for key interactive buttons, active tab indicators, and critical consensus headers.
- **Aged Filament (`#E2D3B3`):** Secondary text, muted state labels, and subtle badges.

### Protocol Signals & Underscore

- **Monad Luminescence (`#836EF9`):** Reserved for cryptographic states, autonomous routing vectors, and zero-knowledge proof traces. Used largely at 8%–24% opacity for atmospheric depth or pure for key agent links.
- **Consensus Emerald (`#10B981`):** Cryptographic verification verified, trust score > 98%, execution confirmed.
- **Dispute Amber (`#F59E0B`):** Slashing conditions pending, agent quorum challenge, latency spike.
- **Security Breach Crimson (`#F43F5E`):** Byzantine behavior detected, unauthorized access attempt, contract lock.

## Typography

The typographic system creates contrast between high-concept machine governance and technical execution:

1. **Syne (Headlines & Display):** Sculptural, wide-aperture geometry. Used sparingly with expansive tracking on uppercase tracking labels and titles to signal architectural prestige.
2. **Geist (Body Text & Natural Language Prompts):** Ultra-clean, hyper-neutral contemporary sans-serif providing high legibility across execution logs and reasoning traces.
3. **JetBrains Mono (Technical & Cryptographic Layer):** Uncompromising precision for agent addresses, hashes, gas variables, trust ratios, and block heights. All numbers within tables and metrics must enforce tabular figures (`tnum`).

## Layout & Spacing

The interface employs a disciplined **12-column dynamic modular grid** flanked by generous margins on desktop, compressing to a structural single- or double-column cockpit on mobile.

- **Vast Negative Space:** Major sections must be framed with ample padding (`space-xl` or greater) to reinforce quiet authority and prevent claustrophobic density despite high information volume.
- **Information Density Wells:** While layout frames remain vast, data panels (such as agent consensus trees and mempool telemetry) switch internally to strict, ultra-compact cadences utilizing `space-xs` and `space-sm`.
- **Responsive Adaptations:**
  - **Desktop (> 1280px):** 12 columns, 48px canvas margins, persistent dual-sidebar architecture (Global Agent Fleet navigation on the left, Execution Stream on the right).
  - **Tablet (768px - 1279px):** 8 columns, 24px canvas margins, collapsable telemetry drawer.
  - **Mobile (< 767px):** 4 columns, 16px margins, stack-oriented feed, bottom-docked quick-action consensus terminal.

## Elevation & Depth

Elevation does not rely on heavy drop shadows or skeuomorphic bevels. Instead, depth is achieved via **Luminescent Layering, Dark Opacities, and Hairline Boundaries**:

- **Ground Level (`#050308`):** Deep canvas background.
- **Layer 1 - Quorum Plates:** Background `#0B0714` at 85% opacity, combined with `backdrop-filter: blur(12px)`. Outlined with a razor-thin 1px border of `#2E1A47` at 60% opacity.
- **Layer 2 - Floating Nodes & Terminals:** Background `#120924` at 92% opacity. Perimeter stroke transitions from `#836EF9` (20% opacity) at the top edge to `#2E1A47` (40% opacity) at the bottom edge, simulating top-down zenith lighting.
- **Active Illumination (The Lantern Glow):** When a node or agent becomes active, it emits an incandescent ambient glow:
  - `box-shadow: 0 0 32px -4px rgba(252, 231, 200, 0.07), 0 0 1px 1px rgba(252, 231, 200, 0.25)`
- **Atmospheric Underglow:** Key interface sectors utilize an anchored radial gradient: `radial-gradient(ellipse 60% 40% at 50% -10%, rgba(131, 110, 249, 0.08), transparent)`.

## Shapes

The design system adheres strictly to **Sharp-to-Soft architectural geometry (`roundedness: 1`)**.

- Containers, cards, tables, and modal frames use `0.25rem` (4px) corner radiuses, yielding an uncompromising, engineered feel reminiscent of tactical aerospace instrumentation.
- Inner elements (chips, badges, input fields) maintain crisp `2px` to `4px` radiuses.
- Complete circular geometry (`rounded-full`) is forbidden for structural components, permitted only for agent avatar indicators, live node status dots, and circular progress rings.
- Divider lines are crisp 1px hair lines with zero blur, fading off radially towards their edges.

## Components

### Buttons

- **Primary (Incandescent Beam):** Solid `#FCE7C8` fill with `#050308` text (`Syne`, 600 weight, uppercase tracking). On hover, brightness surges with a soft edge aura (`box-shadow: 0 0 20px rgba(252, 231, 200, 0.35)`). Active state applies a micro-scale transition of `0.98`.
- **Secondary (Obsidian Glass):** Background `#0B0714` with 1px border `#2E1A47`. Text in `#E2D3B3`. Hover shifts border to `#836EF9` (60% opacity) and background to `#120924`.
- **Destructive / Slash Action:** Transparent background with 1px border `#F43F5E` (40% opacity), text in `#F43F5E`. On hover, fills with `rgba(244, 63, 94, 0.12)`.

### Cards & Execution Nodes

- Composed of `#0B0714` background with `backdrop-filter: blur(16px)`.
- Border: 1px continuous solid border `#2E1A47` (50% opacity).
- Header zone separated by a 1px divider spanning the entire card width.
- Metadata metrics displayed strictly in `JetBrains Mono` with muted labels (`#E2D3B3` at 60% opacity) stacked above incandescent values (`#FFF7EB`).

### Chips & Badges

- **Agent Verification Chip:** Height 22px, padding `0 8px`, 2px radius. Background `rgba(16, 185, 129, 0.08)`, border 1px `rgba(16, 185, 129, 0.3)`, text `#10B981` in `mono-sm`. Contains a 4px pulsing emerald dot.
- **Risk Level Amber:** Background `rgba(245, 158, 11, 0.08)`, border 1px `rgba(245, 158, 11, 0.3)`, text `#F59E0B`.
- **Protocol Tag:** Background `rgba(131, 110, 249, 0.06)`, border 1px `rgba(131, 110, 249, 0.25)`, text `#836EF9`.

### Input Fields & Terminal Prompts

- Background `#050308` with inset 1px border `#2E1A47`.
- Text typed in `Geist` or `JetBrains Mono` depending on execution mode, colored `#FFF7EB`.
- Placeholder text in `#E2D3B3` at 30% opacity.
- Focus state eliminates standard OS rings, replacing them with a crisp 1px `#FCE7C8` border and an ambient `0 0 16px rgba(252, 231, 200, 0.12)` glow.
- Prompt prefixes (e.g., `agent://`, `0x`, `sign >`) rendered in `#836EF9` at 70% opacity.

### Lists & Data Tables

- Header cells: `label-caps` typography, uppercase, text color `#E2D3B3` (50% opacity), zero vertical borders, 1px bottom border `#2E1A47`.
- Rows: Height 48px, hover background `rgba(18, 9, 36, 0.6)`. Transitions smoothly over 150ms.
- Cell numeric entries formatted in `JetBrains Mono` with right alignment for currency, latency, and stake amounts.

### Checkboxes & Binary Selectors

- Sharp square checkboxes (2px radius), 14px × 14px.
- Unchecked: Inset `#050308`, border 1px `#2E1A47`.
- Checked: Background `#FCE7C8`, checkmark icon in `#050308`.

### Specialized Agent Components

- **Agent Consensus Beacon:** A circular state marker flanked by an interactive gas/trust ring. Normal state emits low-frequency breathing pulse; dispute triggers asynchronous crimson flashes.
- **Cryptographic Trace Log:** Monospaced real-time terminal feed featuring expandable zero-knowledge verification steps, transaction hashes with copy triggers, and state root hashes.
